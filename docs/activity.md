## 🟢 Week 4 — Final Project Development (HydroCare System)

### **Day 1 – WAN Configuration**

I expanded my network knowledge by:

* Configuring WAN connections
* Integrating WLAN into the system

This demonstrated how large-scale networks operate.

---

### **Day 2 – Project Proposal**

We submitted our project proposal for:
**“HydroCare Auto Watering Plant System”**

We also started designing:

* Frontend dashboard
* System architecture

---

### **Day 3 – Project Development**

We began building the system:

* Writing Arduino (ESP32) code
* Designing database structure
* Creating web dashboard

The goal was to automate plant watering using sensors.

---

### **Day 4 – Physical Implementation**

We connected all hardware components:

* Soil moisture sensor
* Water pump (via relay)
* LED and buzzer
* ESP32 microcontroller

We tested:

* Sensor readings
* Pump activation
* Alerts (LED and buzzer)

This was the most practical and hands-on day.

---

### **Day 5 – Final Presentation**

We presented our complete system:

* Explained how the system works
* Demonstrated live operation
* Showed the dashboard and data flow

### 🔍 System Overview:

The HydroCare system works as follows:

1. Soil moisture sensor reads data
2. ESP32 processes the data
3. If soil is dry → pump turns ON
4. LED and buzzer provide alerts
5. Data is sent to a database
6. Dashboard displays real-time information
